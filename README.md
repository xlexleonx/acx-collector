# ACROTIX Collector

Локальный сборщик мониторинга для инфраструктуры заказчика. Работает внутри сети заказчика, опрашивает устройства по SNMP v2c, SNMP v3 и IPMI, обнаруживает виртуальные машины ESXi/vCenter, хранит данные локально и передаёт их в Assist Portal через исходящее защищённое соединение.

> Статус: стартовый каркас продукта. Пилотный контур Assist Portal не изменяется.

## Что уже заложено

- Docker-развёртывание для Ubuntu;
- локальная PostgreSQL БД;
- первый вход пользователя `admin` по одноразовому токену;
- роли и разрешения на просмотр/редактирование модулей;
- учёт устройств, зашифрованное хранение параметров SNMP/IPMI;
- подключение VMware ESXi/vCenter по API и автоматическое создание обнаруженных ВМ в списке хостов;
- шаблоны, элементы данных, триггеры и их отключение;
- запуск проверок через `snmpget` и `ipmitool`;
- хранение последних значений, ошибок опроса и событий;
- локальная очередь синхронизации с Assist Portal.

## Архитектура

```text
Оборудование ── SNMP/IPMI ──> collector-api / collector-worker
                                      │
                                  PostgreSQL
                                      │
                            outbox (повторная отправка)
                                      │ HTTPS, только исходящее
                                      v
                                Assist Portal
```

Сборщик не требует входящих соединений из интернета. Портал принимает только нормализованные пакеты с идентификатором инсталляции и подписью.

## Быстрый старт на Ubuntu

1. Скопируйте проект на сервер и установите Docker Engine с Docker Compose plugin.
2. Выполните:

```bash
cd /opt/acx-collector
bash scripts/bootstrap-ubuntu.sh
docker compose up -d --build
```

Скрипт создаст `.env` и одноразовый токен в `secrets/bootstrap_token`. Откройте `http://IP_СЕРВЕРА:8088`, войдите как `admin`, укажите токен и задайте пароль. После этого токен автоматически удаляется.

## Обновление

```bash
cd /opt/acx-collector
git pull --ff-only origin main
docker compose pull
docker compose up -d --build
```

Перед обновлением создавайте резервную копию PostgreSQL:

```bash
docker compose exec -T postgres pg_dump -U acx acx_collector > backups/acx-collector-$(date +%F-%H%M).sql
```

## Шаблоны Zabbix

`scripts/fetch-zabbix-template-catalog.sh` получает официальный каталог шаблонов ветки Zabbix 7.0 в локальный, намеренно неотслеживаемый Git-каталог `vendor/zabbix-templates`. Затем `scripts/import-zabbix-catalog.sh` загружает каталог в базу Collector. Прямые SNMP-элементы активируются; сложные выражения, discovery и зависимые элементы требуют отдельной адаптации и не включаются как ложные триггеры.

Перед включением конкретных шаблонов в распространяемый дистрибутив необходимо проверить их происхождение и лицензию. Импорт собственных экспортов заказчика допускается через интерфейс без включения этих файлов в репозиторий Collector.

## VMware ESXi и vCenter

В «Хосты → Добавить хост» выберите `VMware ESXi` для отдельного гипервизора или `VMware vCenter` для центра управления. Укажите адрес, учётную запись VMware с правом чтения инвентаря и пароль. После сохранения Коллектор проверит подключение и добавит найденные виртуальные машины как управляемые хосты. Кнопка `↻ ВМ` принудительно обновляет список; фоновая синхронизация выполняется раз в 5 минут.

TLS-проверка включена по умолчанию. Для тестового ESXi с самоподписанным сертификатом её можно явно отключить в карточке подключения; в рабочем контуре следует использовать доверенный сертификат.
