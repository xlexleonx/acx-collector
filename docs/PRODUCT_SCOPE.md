# ACROTIX Collector — границы первой версии

## Цель

Собрать телеметрию в локальной сети заказчика, отобразить оператору реальное состояние опроса и передавать подтверждённые данные в Assist Portal без входящего доступа в сеть заказчика.

## Входит в первую рабочую версию

| Контур | Функции |
| --- | --- |
| Инсталляция | Docker Compose, Ubuntu, резервное копирование, обновление и rollback-процедура. |
| Безопасность | Первый вход `admin`, роли, аудит, шифрование учётных данных устройств, исходящий HTTPS. |
| Устройства | SNMP v2c, SNMP v3, IPMI; тест соединения; статус и причина ошибки. |
| Шаблоны | Элементы данных, числовые OID, интервалы, единицы, включение/отключение, пороговые триггеры, YAML/JSON импорт. |
| Опрос | Отдельный worker, последние данные, ошибки каждого элемента, открытие и закрытие проблем. |
| Синхронизация | Локальная outbox-очередь, идемпотентные события, повторная отправка после восстановления связи. |

## Последующие версии

- LLD/автообнаружение интерфейсов, дисков, датчиков и модулей;
- полноценный перевод выражений и зависимых элементов Zabbix;
- графики, агрегация, прогнозирование и гибкие сроки хранения;
- массовый импорт устройств, сетевые карты, несколько polling workers;
- mTLS, MFA/WebAuthn, внешние каталоги пользователей;
- управляемый каталог сертифицированных шаблонов по вендорам.

## Статусы устройства

| Статус | Значение |
| --- | --- |
| `available` | Получен хотя бы один корректный ответ. |
| `unavailable` | Нет ответа от всех активных элементов. Ошибка сохраняется в карточке. |
| `configuration_error` | Нет шаблона, повреждены параметры или указан неподдерживаемый тип. |
| `unknown` | Опрос ещё не выполнялся. |

## Контракт передачи на портал

Сборщик отправляет пакеты `metric.sample`, `problem.opened` и `problem.closed`. Каждый пакет имеет неизменяемый `event_id`. Портал обязан отвечать успешно на повторную доставку уже принятого `event_id`, не создавая дубликатов.
