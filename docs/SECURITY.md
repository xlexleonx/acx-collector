# Безопасность ACROTIX Collector

1. Разворачивайте сборщик в отдельной VLAN/подсети управления, доступной до оборудования.
2. Не открывайте порт UI в Интернет. Ограничьте доступ VPN, ACL или reverse proxy с SSO.
3. Используйте SNMP v3 `authPriv`; SNMP v2c — только для исторически не поддерживающих v3 устройств и с отдельной community на клиента.
4. Не передавайте SNMP/IPMI-пароли в Assist Portal. В портал уходят только метрики, состояния, проблемы и технические идентификаторы устройств.
5. Храните `ACX_MASTER_KEY`, bootstrap-токен и параметры портала в каталоге `secrets/` с правами `600`.
6. Делайте резервную копию PostgreSQL перед каждым обновлением и проверяйте восстановление на стенде.
7. Для связи с порталом используйте валидный публичный TLS-сертификат; в рабочей версии дополнительно включите mTLS.
8. Регулярно обновляйте базовый образ, пакеты `net-snmp`, `ipmitool` и зависимости API.
